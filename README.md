# Ажилтны бүтээмж хянах систем

Python + Tkinter програм. Ажилтан бүртгэж, камераар компьютерийн өмнө **амьд хүн** (зураг, бичлэг биш) сууж байгаа эсэх, тэр нь **бүртгэлтэй ажилтан өөрөө** мөн эсэхийг шалгана. Мөн компьютер дээр ямар програм ажиллаж байгааг зөвшөөрөлтэйгээр хэмжинэ. Браузерын идэвхтэй таб YouTube, Facebook, Instagram, Gmail байвал түүнийг тусад нь танина. Програм, сайт тус бүрт зарцуулсан хугацааг графикаар харуулна. Бүх өгөгдөл JSON файлд хадгалагдана.

**Шаардлага:** Windows 10/11, Python 3.10 ба түүнээс шинэ (3.12, 3.14 дээр шалгасан), камер (ажилтны компьютерт).

## Суулгах, ажиллуулах

```
python -m pip install -r requirements.txt
python main.py
```

## Хоёр эрх: админ ба ажилтан

Програм нээгдэхэд нэвтрэх цонх гарна.

| | Админ | Ажилтан |
|---|---|---|
| Нэвтрэх | нууц үгээр (анх оруулсан нууц үг хадгалагдана) | админы компьютерийн хаяг, өөрийн нэр, код |
| Табууд | Ажилтны бүртгэл, Ажлын бүтээмж | Камер, Компьютерийн идэвх |
| Хийх зүйл | ажилтан бүртгэх, устгах, нүүрийг нь устгах, бүх хүний програм, сайтын хугацаа, камерын шалгалтыг харах | нүүрээ бүртгүүлэх, камер, өөрийн идэвхийг хэмжээд админ руу илгээх |
| Өгөгдөл | бүх JSON файл зөвхөн админы компьютерт хадгалагдана | өөрт нь юу ч хадгалагдахгүй |

**Сервер:** админ нэвтэрмэгц түүний компьютер JSON сервер болно (порт `5050`). Ажилтан нэвтрэхэд сервер түүний нүүрний хээг буцааж өгч, ажилтны **камер шууд асна**. Ажилтан «Түр зогсоох» дарахад шалтгаан нь админ руу очиж `pauses.json`-д хадгалагдана. «Дуусгах» дарахад идэвхийн болон камерын хураангуй JSON хэлбэрээр админы компьютер руу очиж `activity.json`-д хадгалагдана. Админы «Ажлын бүтээмж» хүснэгт 5 секунд тутам шинэчлэгдэнэ.

- **Админы компьютер:** анх асаахад Windows firewall асуувал «Allow» дарна. Ажилтнууд «Админы компьютер» талбарт админы компьютерийн нэр эсвэл IP хаягийг бичнэ.
- **Нэг компьютер дээр турших:** програмыг 2 удаа нээнэ. Эхнийхийг нь админаар нэвтрүүлнэ. Хоёр дахийг нь ажилтнаар `127.0.0.1` хаягаар нэвтрүүлнэ.

## Ашиглах дараалал

1. **Админ:** нууц үгээр нэвтэрч, «Ажилтны бүртгэл» дээр нэр, кодыг (дор хаяж 4 тэмдэгт) бичээд «Бүртгэх» дарна. Нэр, кодыг ажилтанд хэлж өгнө. Аль хэдийн байгаа нэрийг дахин бүртгэвэл код нь шинэчлэгдэнэ. Кодгүй хуучин ажилтанд код өгөхдөө ингэнэ.
2. **Ажилтан:** админы компьютерийн хаяг, өөрийн нэр, кодыг бичээд «Нэвтрэх» дарна. Нэрийн том, жижиг үсэг хамаагүй. Нэвтэрмэгц камер асаж, амьд хүн шалгалт эхэлнэ (доор).
3. **Ажилтан, Камер, нүүр бүртгэх** (нэг удаа): «Нүүр бүртгэх» дараад дэлгэцийн зааврыг дагана. Нүүрний хээ админы компьютерт хадгалагдаж, админы жагсаалтын «Нүүр» баганад «бүртгэсэн» гэж гарна. Ажилтан нүүрээ өөрөө дахин бүртгэж чадахгүй. Шинэчлэх бол админ «Нүүр устгах» дарна. Анхны бүртгэлийг админы дэргэд хийх нь зөв, эс бөгөөс ажилтан өөрийн оронд өөр хүний нүүрийг бүртгүүлж болно.
4. **Ажилтан, Компьютерийн идэвх:** «Хэмжилт эхлэх» дарна. Камерын хугацаа (ажилтан өөрөө, өөр хүн, хүн алга, баталгаажаагүй) зөвхөн хэмжилтийн үеэр тоологдоно. Камерыг хаасан байсан бол дахин асна. «Түр зогсоох» дарахад шалтгаан асууна, шалтгаан нь админ руу илгээгдэнэ. Дахин «Хэмжилт эхлэх» дарвал үргэлжилнэ. Хэмжилтийн явцад програм, сайт тус бүрийн хугацаа баганан графикаар харагдана. Хэмжилтийн үеэр камерыг гараар хаах боломжгүй. Эцэст нь «Дуусгах» дарахад үр дүн админ руу илгээгдэнэ. Камер асаалттай үлдэж, програмыг хаахад унтарна.
5. **Админ, Ажлын бүтээмж:** ажилтан бүрийн нийт хугацаа, YouTube, Facebook, Instagram, Gmail дээр зарцуулсан минут, хамгийн их хэрэглэсэн програм, сүүлд түр зогсоосон шалтгаан, камерт **өөр хүн** суусан болон **баталгаажаагүй** минутыг нэг хүснэгтээр харна. Ажилтны бүх хэмжилт нийлж харагдана.

**Таб таних хязгаар:** Windows цонхны гарчигт зөвхөн браузерын **идэвхтэй таб** гардаг. Тиймээс тухайн табыг нээж харж байх үеийн хугацаа бүртгэгдэнэ, ард нээлттэй байгаа табууд тоологдохгүй.

## Камер хэрхэн шалгадаг вэ

Ажилтан админы серверт нэвтэрмэгц камерын таб нээгдэж, заавар гарна: камер руу шууд харах, нүдээ 1 секунд аниад нээх, толгойгоо зааврын дагуу зүүн, баруун тийш эргүүлэх. Дараалал нь санамсаргүй бөгөөд зүүн, баруун чиглэлийг дэлгэц дээр сумаар харуулна. Дараа нь камер суусан хүнийг бүртгэлтэй нүүртэй байнга харьцуулна.

| Шалгалт | Арга | Юуг илрүүлнэ |
|---|---|---|
| Нүдээ аних | Нээлттэй нүд илрүүлэгч (Haar) 2 нүдийг олохоо больж, дахин олох. Толгой хөдлөөгүй байх ёстой | **Зураг**: зураг нүдээ аньж чадахгүй |
| Толгой эргүүлэх | Нүд, амны 4 цэгийн хавтгайгаас хамар хажуу тийш зөрөх (параллакс). Дараалал санамсаргүй, буруу тийш эргүүлбэл шууд амжилтгүй | **Урьдчилан бичсэн бичлэг**: дарааллыг мэдэхгүй |
| Хэн сууж байна | Нүүрний 128 тооны хээ (SFace), бүртгэсэн хээтэй cosine ≥ 0.363. Секундэд ~3 удаа, сүүлийн 5-ын олонхоор | **Өөр хүн** ажилтны оронд суусан |

Дахин шалгах үе: хүн 5 сек-ээс удаан алга болоод буцаж ирэхэд, мөн 10 минут тутам. Энэ үед цонх урд гарч дуу гаргана. 25 секундэд зааврыг биелүүлэхгүй бол «баталгаажаагүй» гэж тоолж, 3 секундын дараа дахин шалгана.

**Хязгаарлалт:** шууд видео дуудлагаар өөр хүн заавар дагаж байвал илрүүлэхгүй. Нүдний зай 40 пикселээс бага (хүн камераас хол, ойролцоогоор 75 см-ээс цааш) бол шалгалт хийгдэхгүй. Нүдний шил хүчтэй гэрэл ойлгож байвал нүд илрүүлэлт алдаж болно.

## Файлууд

| Файл | Гишүүн | Үүрэг | Гол функц |
|---|---|---|---|
| `main.py` | 1 | Нэвтрэх цонх, админ болон ажилтны табууд, бусад модулийг холбоно | `ProductivityApp` |
| `register.py` | 2 | Ажилтны бүртгэл, нүүрний хээ, JSON хадгалалт, админы нууц үг, JSON сервер | `list_employees`, `add_employee`, `delete_employee`, `get_face`, `save_face`, `delete_face`, `save_activity`, `activities`, `save_pause`, `last_pause`, `check_password`, `start_server`, `serve`, `ask` |
| `camera.py` | 3 | Камер, нүүр илрүүлэлт (YuNet), амьд хүн шалгалт, ажилтныг таних (SFace) | `CameraService`, `LivenessCheck`, `FaceEnrollment`, `FaceMonitor` |
| `activity.py` | 4 | Урд талын програм, танигдсан сайт (YouTube, Facebook, Instagram, Gmail), хугацаа | `active_app`, `ActivityTracker.start`, `pause`, `resume`, `tick`, `stop` |
| `productivity.py` | 5 | Идэвхийн хураангуй: хэмжилтүүдийг нийлүүлэх, 4 сайтын хугацаа, хамгийн их програм, камерын шалгалт | `total_apps`, `site_times`, `top_app`, `camera_totals`, `minutes` |

**Алгоритм:** товч дарах → утга шалгах → модуль дуудах → JSON-д хадгалах → үр дүн харуулах.

## Өгөгдөл

Өгөгдөл програмын хажууд байх `data\` хавтаст хадгалагдана. `python main.py` ажиллуулбал төслийн хавтаст, `.exe` ажиллуулбал `.exe`-ийн хажууд үүснэ. Төсөлд жишээ өгөгдөлтэй 2 файл бий:

| Файл | Агуулга |
|---|---|
| `employees.json` | Ажилтнууд: ID, нэр, кодын хэш |
| `activity.json` | Хэмжилт бүрийн хураангуй: нийт секунд, програм, сайт тус бүрийн секунд (жишээ нь `chrome.exe - YouTube`), камерын хураангуй (`camera`) |
| `pauses.json` | Ажилтан түр зогсоохдоо админ руу илгээсэн шалтгаан, цаг (хэмжилт хийгдсэний дараа үүснэ) |
| `faces.json` | Нүүрний хээ: ажилтан бүрт 128 тоо (ажилтан нүүрээ бүртгүүлсний дараа үүснэ) |

`camera` хураангуй: `owner_seconds` (ажилтан өөрөө), `other_seconds` (өөр хүн), `no_face_seconds` (хүн алга), `unverified_seconds` (амьд хүн шалгалт явагдаж байсан, амжилтгүй эсвэл нүүр бүртгээгүй), `liveness_failures` (амжилтгүй шалгалтын тоо).

Өгөгдөл `.exe` дотор биш тусдаа хавтаст байдаг тул програмыг хааж дахин нээхэд устахгүй.

Мөн `admin.json` файлд админы нууц үгийн SHA-256 хэш хадгалагдана, нууц үг өөрөө хадгалагдахгүй. Ажилтны код ч мөн адил зөвхөн хэш хэлбэрээр хадгалагдана. `admin.json`, `faces.json` хоёр git-д орохгүй (`.gitignore`). Нууц үгээ мартвал `data\admin.json`-ийг устгаад шинэ нууц үгээр нэвтэрнэ.

Загварууд `models\` хавтаст байна: `face_detection_yunet_2023mar.onnx` (нүүр + 5 цэг, MIT), `face_recognition_sface_2021dec.onnx` (нүүрний хээ, Apache 2.0). Хоёулаа [OpenCV Zoo](https://github.com/opencv/opencv_zoo)-оос.

## Ашигласан сан (12)

- **Python-д анхнаасаа байдаг:** `tkinter`, `json`, `os`, `sys`, `time`, `random`, `ctypes`, `socket` (сервер), `hashlib` (нууц үг)
- **Суулгах ёстой:** `opencv-python` (`cv2`), `numpy` (OpenCV-тэй хамт суудаг), `pyinstaller`

OpenCV-г 5-аас доош хувилбараар суулгана, учир нь OpenCV 5-д нээлттэй нүд илрүүлэх Haar cascade байхгүй.

## .exe гаргах

```
python build_exe.py
```

Үр дүн нь `dist\ProductivitySystem.exe` файл болно. Python суулгаагүй Windows компьютер дээр ч давхар товшоод ажиллана.

## Нууцлал

- **Камер:** ажилтан админы серверт нэвтэрсэн үед асна. Хугацааг зөвхөн хэмжилт явагдаж байх үед тоолно. Хэмжилт хийгээгүй үед ажилтан «Камер хаах» дарж болно. Зураг, бичлэг хадгалахгүй. Ажилтан «Нүүр бүртгэх» дарсан үед л нүүрний 128 тооны хээг админы компьютерийн `faces.json`-д хадгална. Үүнээс нүүрний зургийг сэргээх боломжгүй. Ажилтныг эсвэл нүүрийг нь устгахад хээ нь хамт устна. Энэ нь биометрийн өгөгдөл тул ажилтны зөвшөөрлийг авна.
- **Идэвх:** зөвхөн «Хэмжилт эхлэх» дарсны дараа хэмжинэ. Програмын нэр (жишээ нь `Code.exe`), хугацааг бүртгэнэ. Браузерын цонхны гарчгаас зөвхөн YouTube, Facebook, Instagram, Gmail гэсэн нэр таарч байгаа эсэхийг шалгаж, таарвал сайтын нэрийг л хадгална. Гарчиг өөрөө, хуудасны агуулга, товчлуурын даралт, дэлгэцийн зураг хадгалагдахгүй.
- Програм, сайтын хугацаа нь ажлын чанарыг баталгаажуулахгүй, зөвхөн цагийг харуулна.

# Ажилтны идэвх хянах систем

Python + Tkinter програм. Ажилтан бүртгэж, камераар нүүр байгаа эсэхийг шалгана. Хэмжилтийг эхлүүлсний дараа идэвхтэй програм болон танигдсан браузерын сайтуудад зарцуулсан хугацааг графикаар харуулж, JSON файлд хадгална.

**Шаардлага:** Windows 10/11, Python 3.10 ба түүнээс шинэ (3.12 дээр шалгасан).

## Суулгах, ажиллуулах

```
python -m pip install -r requirements.txt
python main.py
```

## Ашиглах дараалал

1. **Ажилтны бүртгэл:** нэрээ бичээд «Бүртгэх» дарна.
2. Цонхны дээд талын **«Ажилтан»** жагсаалтаас ажилтнаа сонгоно.
3. **Камер:** «Камер нээх» дарахад илэрсэн нүүрний тоо харагдана. «Камер хаах» дарж хаана.
4. **Компьютерийн идэвх:** «Хэмжилт эхлэх», «Түр зогсоох», «Дуусгах» товчнуудаар хугацааг хэмжиж, ашигласан програм болон танигдсан браузерын сайтуудыг графикаар харуулна.

## Файлууд

| Файл | Гишүүн | Үүрэг | Гол функц |
|---|---|---|---|
| `main.py` | 1 | Tkinter цонх, 3 таб, бусад модулийг холбоно | `ProductivityApp` |
| `register.py` | 2 | Ажилтны бүртгэл, JSON хадгалалт | `list_employees`, `add_employee`, `delete_employee`, `save_activity` |
| `camera.py` | 3 | Камер, нүүр илрүүлэлт (OpenCV Haar cascade) | `CameraService.start`, `get_frame`, `stop` |
| `activity.py` | 4 | Урд талын програм, танигдсан сайт, хугацаа | `active_app`, `ActivityTracker.start`, `pause`, `resume`, `tick`, `stop` |
| `build_exe.py` | 5 | `.exe` гаргах | — |

**Алгоритм:** хэмжилт эхлүүлэх → програм/танигдсан сайтын ашигласан хугацааг тооцох → график харуулах → JSON-д хадгалах.

## Өгөгдөл

Өгөгдөл програмын хажууд байх `data\` хавтаст хадгалагдана. `python main.py` ажиллуулбал төслийн хавтаст, `.exe` ажиллуулбал `.exe`-ийн хажууд үүснэ. Төсөлд ажилтан болон идэвхийн жишээ өгөгдөл бий:

| Файл | Агуулга |
|---|---|
| `employees.json` | Ажилтнуудын нэр, бүртгэлийн дугаар |
| `activity.json` | Идэвхийн хураангуй: нийт секунд, програм тус бүрийн секунд |

Өгөгдөл `.exe` дотор биш тусдаа хавтаст байдаг тул програмыг хааж дахин нээхэд устахгүй.

## Ашигласан сан (7)

- **Python-д анхнаасаа байдаг:** `tkinter`, `json`, `os`, `time`, `ctypes`
- **Суулгах ёстой:** `opencv-python` (`cv2`), `pyinstaller`

OpenCV-г 5-аас доош хувилбараар суулгана, учир нь OpenCV 5-д нүүр илрүүлэх Haar cascade байхгүй.

## .exe гаргах

```
python build_exe.py
```

Үр дүн нь `dist\ProductivitySystem.exe` файл болно (~64 MB). Python суулгаагүй Windows компьютер дээр ч давхар товшоод ажиллана.

## Нууцлал

- **Камер:** зөвхөн кадрт нүүр байгаа эсэхийг тоолно. Хэн болохыг танихгүй, зураг, бичлэг хадгалахгүй.
- **Идэвх:** зөвхөн «Хэмжилт эхлэх» дарсны дараа хэмжинэ. Програмын нэр, мөн браузерын цонхны гарчгаас YouTube, Facebook, Instagram, Gmail-ийн нэр таарвал сайтын нэр ба хугацааг бүртгэнэ. Хуудасны агуулга, товчлуурын даралт, дэлгэцийн зураг авахгүй.

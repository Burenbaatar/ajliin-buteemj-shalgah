# Ажилтны бүтээмж хянах систем

Python + Tkinter програм. Ажилтан бүртгэж, камераар нүүр байгаа эсэхийг шалгана. Мөн компьютер дээр ямар програм ажиллаж байгааг зөвшөөрөлтэйгээр хэмжинэ. Браузерын идэвхтэй таб YouTube, Facebook, Instagram, Gmail байвал түүнийг тусад нь танина. Програм, сайт тус бүрт зарцуулсан хугацааг графикаар харуулна. Бүх өгөгдөл JSON файлд хадгалагдана.

**Шаардлага:** Windows 10/11, Python 3.10 ба түүнээс шинэ (3.12 дээр шалгасан).

## Суулгах, ажиллуулах

```
python -m pip install -r requirements.txt
python main.py
```

## Хоёр эрх: админ ба ажилтан

Програм нээгдэхэд нэвтрэх цонх гарна.

| | Админ | Ажилтан |
|---|---|---|
| Нэвтрэх | нууц үгээр (анх оруулсан нууц үг хадгалагдана) | админы компьютерийн хаяг, өөрийн нэр, код |
| Табууд | Ажилтны бүртгэл, Ажлын бүтээмж | Камер, Компьютерийн идэвх |
| Хийх зүйл | ажилтан бүртгэх, устгах, бүх хүний програм, сайтын хугацааг харах | камер, өөрийн идэвхийг хэмжээд админ руу илгээх |
| Өгөгдөл | бүх JSON файл зөвхөн админы компьютерт хадгалагдана | өөрт нь юу ч хадгалагдахгүй |

**Сервер:** админ нэвтэрмэгц түүний компьютер JSON сервер болно (порт `5050`). Ажилтан «Түр зогсоох» дарахад шалтгаан нь админ руу очиж `pauses.json`-д хадгалагдана. «Дуусгах» дарахад идэвхийн хураангуй JSON хэлбэрээр админы компьютер руу очиж `activity.json`-д хадгалагдана. Админы «Ажлын бүтээмж» хүснэгт 5 секунд тутам шинэчлэгдэнэ.

- **Админы компьютер:** анх асаахад Windows firewall асуувал «Allow» дарна. Ажилтнууд «Админы компьютер» талбарт админы компьютерийн нэр эсвэл IP хаягийг бичнэ.
- **Нэг компьютер дээр турших:** програмыг 2 удаа нээнэ. Эхнийхийг нь админаар нэвтрүүлнэ. Хоёр дахийг нь ажилтнаар `127.0.0.1` хаягаар нэвтрүүлнэ.

## Ашиглах дараалал

1. **Админ:** нууц үгээр нэвтэрч, «Ажилтны бүртгэл» дээр нэр, кодыг (дор хаяж 4 тэмдэгт) бичээд «Бүртгэх» дарна. Нэр, кодыг ажилтанд хэлж өгнө. Аль хэдийн байгаа нэрийг дахин бүртгэвэл код нь шинэчлэгдэнэ. Кодгүй хуучин ажилтанд код өгөхдөө ингэнэ.
2. **Ажилтан:** админы компьютерийн хаяг, өөрийн нэр, кодыг бичээд «Нэвтрэх» дарна. Нэрийн том, жижиг үсэг хамаагүй.
3. **Ажилтан, Камер:** «Камер нээх» дарахад илэрсэн нүүрний тоо харагдана.
4. **Ажилтан, Компьютерийн идэвх:** «Хэмжилт эхлэх» дарна. «Түр зогсоох» дарахад шалтгаан асууна, шалтгаан нь админ руу илгээгдэнэ. Дахин «Хэмжилт эхлэх» дарвал үргэлжилнэ. Хэмжилтийн явцад програм, сайт тус бүрийн хугацаа баганан графикаар харагдана. Эцэст нь «Дуусгах» дарахад үр дүн админ руу илгээгдэнэ.
5. **Админ, Ажлын бүтээмж:** ажилтан бүрийн нийт хугацаа, YouTube, Facebook, Instagram, Gmail дээр зарцуулсан минут, хамгийн их хэрэглэсэн програм, сүүлд түр зогсоосон шалтгааныг нэг хүснэгтээр харна. Ажилтны бүх хэмжилт нийлж харагдана.

**Таб таних хязгаар:** Windows цонхны гарчигт зөвхөн браузерын **идэвхтэй таб** гардаг. Тиймээс тухайн табыг нээж харж байх үеийн хугацаа бүртгэгдэнэ, ард нээлттэй байгаа табууд тоологдохгүй.

## Файлууд

| Файл | Гишүүн | Үүрэг | Гол функц |
|---|---|---|---|
| `main.py` | 1 | Нэвтрэх цонх, админ болон ажилтны табууд, бусад модулийг холбоно | `ProductivityApp` |
| `register.py` | 2 | Ажилтны бүртгэл, JSON хадгалалт, админы нууц үг, JSON сервер | `list_employees`, `add_employee`, `delete_employee`, `save_activity`, `activities`, `save_pause`, `last_pause`, `check_password`, `start_server`, `serve`, `ask` |
| `camera.py` | 3 | Камер, нүүр илрүүлэлт (OpenCV Haar cascade) | `CameraService.start`, `get_frame`, `stop` |
| `activity.py` | 4 | Урд талын програм, танигдсан сайт (YouTube, Facebook, Instagram, Gmail), хугацаа | `active_app`, `ActivityTracker.start`, `pause`, `resume`, `tick`, `stop` |
| `productivity.py` | 5 | Идэвхийн хураангуй: хэмжилтүүдийг нийлүүлэх, 4 сайтын хугацаа, хамгийн их програм | `total_apps`, `site_times`, `top_app`, `minutes` |
| `build_exe.py` | 5 | `.exe` гаргах | — |

**Алгоритм:** товч дарах → утга шалгах → модуль дуудах → JSON-д хадгалах → үр дүн харуулах.

## Өгөгдөл

Өгөгдөл програмын хажууд байх `data\` хавтаст хадгалагдана. `python main.py` ажиллуулбал төслийн хавтаст, `.exe` ажиллуулбал `.exe`-ийн хажууд үүснэ. Төсөлд жишээ өгөгдөлтэй 2 файл бий:

| Файл | Агуулга |
|---|---|
| `employees.json` | Ажилтнууд: ID, нэр, кодын хэш |
| `activity.json` | Хэмжилт бүрийн хураангуй: нийт секунд, програм, сайт тус бүрийн секунд (жишээ нь `chrome.exe - YouTube`) |
| `pauses.json` | Ажилтан түр зогсоохдоо админ руу илгээсэн шалтгаан, цаг (хэмжилт хийгдсэний дараа үүснэ) |

Өгөгдөл `.exe` дотор биш тусдаа хавтаст байдаг тул програмыг хааж дахин нээхэд устахгүй.

Мөн `admin.json` файлд админы нууц үгийн SHA-256 хэш хадгалагдана, нууц үг өөрөө хадгалагдахгүй. Ажилтны код ч мөн адил зөвхөн хэш хэлбэрээр хадгалагдана. Энэ файл git-д орохгүй (`.gitignore`). Нууц үгээ мартвал `data\admin.json`-ийг устгаад шинэ нууц үгээр нэвтэрнэ.

## Ашигласан сан (9)

- **Python-д анхнаасаа байдаг:** `tkinter`, `json`, `os`, `time`, `ctypes`, `socket` (сервер), `hashlib` (нууц үг)
- **Суулгах ёстой:** `opencv-python` (`cv2`), `pyinstaller`

OpenCV-г 5-аас доош хувилбараар суулгана, учир нь OpenCV 5-д нүүр илрүүлэх Haar cascade байхгүй.

## .exe гаргах

```
python build_exe.py
```

Үр дүн нь `dist\ProductivitySystem.exe` файл болно (~64 MB). Python суулгаагүй Windows компьютер дээр ч давхар товшоод ажиллана.

## Нууцлал

- **Камер:** зөвхөн кадрт нүүр байгаа эсэхийг тоолно. Хэн болохыг танихгүй, зураг, бичлэг хадгалахгүй.
- **Идэвх:** зөвхөн «Хэмжилт эхлэх» дарсны дараа хэмжинэ. Програмын нэр (жишээ нь `Code.exe`), хугацааг бүртгэнэ. Браузерын цонхны гарчгаас зөвхөн YouTube, Facebook, Instagram, Gmail гэсэн нэр таарч байгаа эсэхийг шалгаж, таарвал сайтын нэрийг л хадгална. Гарчиг өөрөө, хуудасны агуулга, товчлуурын даралт, дэлгэцийн зураг хадгалагдахгүй.
- Програм, сайтын хугацаа нь ажлын чанарыг баталгаажуулахгүй, зөвхөн цагийг харуулна.

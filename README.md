# Ажилтны бүтээмж хянах систем

Python + Tkinter програм. Ажилтан бүртгэж, камераар нүүр байгаа эсэхийг шалгана. Мөн компьютерийн идэвхийг зөвшөөрөлтэйгээр хэмжинэ: програм болон танигдсан сайт тус бүрт зарцуулсан хугацааг графикаар харуулна. Даалгаврын биелэлтийн хувийг тооцоолно. Бүх өгөгдөл JSON файлд хадгалагдана.

**Шаардлага:** Windows 10/11, Python 3.10 ба түүнээс шинэ (3.12 дээр шалгасан).

## Суулгах, ажиллуулах

```
python -m pip install -r requirements.txt
python main.py
```

## Хоёр эрх: админ ба ажилтан

Програм нээгдэхэд нэвтрэх цонх гарна.

| | Админ | Ажилтан |
|---|---|---|
| Нэвтрэх | нууц үгээр (анх оруулсан нууц үг хадгалагдана) | админы компьютерийн хаяг → «Холбогдох» → нэрээ сонгох |
| Табууд | Ажилтны бүртгэл, Бүтээмж, Ажлын бүтээмж | Камер, Компьютерийн идэвх |
| Хийх зүйл | ажилтан бүртгэх, устгах, гүйцэтгэл оруулж хувь бодох, бүх хүний бүтээмж харах | камер, өөрийн идэвхийг хэмжээд админ руу илгээх |
| Өгөгдөл | бүх JSON файл зөвхөн админы компьютерт хадгалагдана | өөрт нь юу ч хадгалагдахгүй |

**Сервер:** админ нэвтэрмэгц түүний компьютер JSON сервер болно (порт `5050`). Ажилтан «Түр зогсоох» үед шалтгаан админ руу илгээгдэж `pauses.json`-д хадгалагдана; «Ажлын бүтээмж» хүснэгтэд харагдана. «Дуусгах» дарахад идэвхийн хураангуй `activity.json`-д хадгалагдана. Админы «Ажлын бүтээмж» хүснэгт 5 секунд тутам шинэчлэгдэнэ.

- **Админы компьютер:** анх асаахад Windows firewall асуувал «Allow» дарна. Ажилтнууд «Админы компьютер» талбарт админы компьютерийн нэр эсвэл IP хаягийг бичнэ.
- **Нэг компьютер дээр турших:** програмыг 2 удаа нээнэ. Эхнийхийг нь админаар нэвтрүүлнэ. Хоёр дахийг нь ажилтнаар `127.0.0.1` хаягаар нэвтрүүлнэ.

## Ашиглах дараалал

1. **Админ:** нууц үгээр нэвтэрч, «Ажилтны бүртгэл» дээр нэр, төлөвлөсөн даалгаврын тоог бичээд «Бүртгэх» дарна.
2. **Ажилтан:** админы компьютерт холбогдож нэрээ сонгоод нэвтэрнэ.
3. **Ажилтан, Камер:** «Камер нээх» дарахад илэрсэн нүүрний тоо харагдана.
4. **Ажилтан, Компьютерийн идэвх:** «Хэмжилт эхлэх» дарна. «Түр зогсоох» дарахад шалтгаан асууж админ руу илгээнэ. Хэмжилтийн явцад програм, сайт тус бүрийн хугацаа баганан графикаар харагдана. Эцэст нь «Дуусгах» дарахад үр дүн админ руу илгээгдэнэ.
5. **Админ, Бүтээмж:** ажилтнаа сонгож гүйцэтгэсэн тоог бичээд «Хувь бодох» дарна. Сүүлийн идэвх тайланд орно.
6. **Админ, Ажлын бүтээмж:** бүх ажилтны биелэлт, идэвхийг нэг хүснэгтээр харна.

## Файлууд

| Файл | Гишүүн | Үүрэг | Гол функц |
|---|---|---|---|
| `main.py` | 1 | Нэвтрэх цонх, админ болон ажилтны табууд, бусад модулийг холбоно | `ProductivityApp` |
| `register.py` | 2 | Ажилтны бүртгэл, JSON хадгалалт, админы нууц үг, JSON сервер | `list_employees`, `add_employee`, `update_progress`, `delete_employee`, `save_activity`, `last_activity`, `save_report`, `check_password`, `start_server`, `serve`, `ask` |
| `camera.py` | 3 | Камер, нүүр илрүүлэлт (OpenCV Haar cascade) | `CameraService.start`, `get_frame`, `stop` |
| `activity.py` | 4 | Урд талын програм, танигдсан сайт (YouTube, Facebook, Instagram, Gmail), хугацаа | `active_app`, `ActivityTracker.start`, `pause`, `resume`, `tick`, `stop` |
| `productivity.py` | 5 | Биелэлтийн хувь, тайлан | `calculate_completion`, `build_report`, `report_text` |
| `build_exe.py` | 5 | `.exe` гаргах | — |

**Алгоритм:** товч дарах → утга шалгах → модуль дуудах → JSON-д хадгалах → үр дүн харуулах.

## Өгөгдөл

Өгөгдөл програмын хажууд байх `data\` хавтаст хадгалагдана. `python main.py` ажиллуулбал төслийн хавтаст, `.exe` ажиллуулбал `.exe`-ийн хажууд үүснэ. Төсөлд жишээ өгөгдөлтэй 3 файл бий:

| Файл | Агуулга |
|---|---|
| `employees.json` | Ажилтнууд: нэр, төлөвлөсөн даалгавар, дууссан даалгавар |
| `activity.json` | Идэвхийн хураангуй: нийт секунд, програм тус бүрийн секунд |
| `pauses.json` | Ажилтан түр зогсоохдоо админ руу илгээсэн шалтгаан, цаг |
| `reports.json` | Тооцоолсон тайлангууд |

Өгөгдөл `.exe` дотор биш тусдаа хавтаст байдаг тул програмыг хааж дахин нээхэд устахгүй.

Мөн `admin.json` файлд админы нууц үгийн SHA-256 хэш хадгалагдана, нууц үг өөрөө хадгалагдахгүй. Энэ файл git-д орохгүй (`.gitignore`). Нууц үгээ мартвал `data\admin.json`-ийг устгаад шинэ нууц үгээр нэвтэрнэ.

## Ашигласан сан (9)

- **Python-д анхнаасаа байдаг:** `tkinter`, `json`, `os`, `time`, `ctypes`, `socket` (сервер), `hashlib` (нууц үг)
- **Суулгах ёстой:** `opencv-python` (`cv2`), `pyinstaller`

OpenCV-г 5-аас доош хувилбараар суулгана, учир нь OpenCV 5-д нүүр илрүүлэх Haar cascade байхгүй.

## .exe гаргах

```
python build_exe.py
```

Үр дүн нь `dist\ProductivitySystem.exe` файл болно (~64 MB). Python суулгаагүй Windows компьютер дээр ч давхар товшоод ажиллана.

## Нууцлал

- **Камер:** зөвхөн кадрт нүүр байгаа эсэхийг тоолно. Хэн болохыг танихгүй, зураг, бичлэг хадгалахгүй.
- **Идэвх:** зөвхөн «Хэмжилт эхлэх» дарсны дараа хэмжинэ. Програмын нэр (жишээ нь `Code.exe`), хугацааг бүртгэнэ. Браузерын цонхны гарчгаас зөвхөн YouTube, Facebook, Instagram, Gmail гэсэн нэр таарч байгаа эсэхийг шалгаж, таарвал сайтын нэрийг л хадгална. Гарчиг өөрөө, хуудасны агуулга, товчлуурын даралт, дэлгэцийн зураг хадгалагдахгүй.
- **Биелэлтийн хувь** = дууссан / төлөвлөсөн × 100. Камер болон идэвхийн хугацаа нь ажлын чанарыг баталгаажуулахгүй.

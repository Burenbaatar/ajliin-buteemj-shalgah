# Ажилтны бүтээмж хянах систем

Python + Tkinter програм. Ажилтан бүртгэж, камераар нүүр байгаа эсэхийг шалгана. Мөн компьютерийн идэвхийг зөвшөөрөлтэйгээр хэмжиж, даалгаврын биелэлтийн хувийг тооцоолно. Бүх өгөгдөл JSON файлд хадгалагдана.

**Шаардлага:** Windows 10/11, Python 3.10 ба түүнээс шинэ (3.12 дээр шалгасан).

## Суулгах, ажиллуулах

```
python -m pip install -r requirements.txt
python main.py
```

## Ашиглах дараалал

1. **Ажилтны бүртгэл:** нэр, төлөвлөсөн даалгаврын тоог бичээд «Бүртгэх» дарна.
2. Цонхны дээд талын **«Ажилтан»** жагсаалтаас ажилтнаа сонгоно.
3. **Камер:** «Камер нээх» дарахад илэрсэн нүүрний тоо харагдана. «Камер хаах» дарж хаана.
4. **Компьютерийн идэвх:** «Хэмжилт эхлэх», «Түр зогсоох», «Дуусгах» товчнууд байна.
5. **Бүтээмж:** гүйцэтгэсэн даалгаврын тоог бичээд «Хувь бодох» дарна.

## Файлууд

| Файл | Гишүүн | Үүрэг | Гол функц |
|---|---|---|---|
| `main.py` | 1 | Tkinter цонх, 4 таб, бусад модулийг холбоно | `ProductivityApp` |
| `register.py` | 2 | Ажилтны бүртгэл, JSON хадгалалт | `list_employees`, `add_employee`, `update_progress`, `delete_employee`, `save_activity`, `save_report` |
| `camera.py` | 3 | Камер, нүүр илрүүлэлт (OpenCV Haar cascade) | `CameraService.start`, `get_frame`, `stop` |
| `activity.py` | 4 | Урд талын програмын нэр ба хугацаа | `active_app`, `ActivityTracker.start`, `pause`, `resume`, `tick`, `stop` |
| `productivity.py` | 5 | Биелэлтийн хувь, тайлан | `calculate_completion`, `build_report`, `report_text` |
| `build_exe.py` | 5 | `.exe` гаргах | — |

**Алгоритм:** товч дарах → утга шалгах → модуль дуудах → JSON-д хадгалах → үр дүн харуулах.

## Өгөгдөл

Өгөгдөл програмын хажууд байх `data\` хавтаст хадгалагдана. `python main.py` ажиллуулбал төслийн хавтаст, `.exe` ажиллуулбал `.exe`-ийн хажууд үүснэ. Төсөлд жишээ өгөгдөлтэй 3 файл бий:

| Файл | Агуулга |
|---|---|
| `employees.json` | Ажилтнууд: нэр, төлөвлөсөн даалгавар, дууссан даалгавар |
| `activity.json` | Идэвхийн хураангуй: нийт секунд, програм тус бүрийн секунд |
| `reports.json` | Тооцоолсон тайлангууд |

Өгөгдөл `.exe` дотор биш тусдаа хавтаст байдаг тул програмыг хааж дахин нээхэд устахгүй.

## Ашигласан сан (7)

- **Python-д анхнаасаа байдаг:** `tkinter`, `json`, `os`, `time`, `ctypes`
- **Суулгах ёстой:** `opencv-python` (`cv2`), `pyinstaller`

OpenCV-г 5-аас доош хувилбараар суулгана, учир нь OpenCV 5-д нүүр илрүүлэх Haar cascade байхгүй.

## .exe гаргах

```
python build_exe.py
```

Үр дүн нь `dist\ProductivitySystem.exe` файл болно (~64 MB). Python суулгаагүй Windows компьютер дээр ч давхар товшоод ажиллана.

## Нууцлал

- **Камер:** зөвхөн кадрт нүүр байгаа эсэхийг тоолно. Хэн болохыг танихгүй, зураг, бичлэг хадгалахгүй.
- **Идэвх:** зөвхөн «Хэмжилт эхлэх» дарсны дараа хэмжинэ. Програмын нэр (жишээ нь `Code.exe`), хугацааг л бүртгэнэ. Товчлуурын даралт, цонхны гарчиг, дэлгэцийн зураг авахгүй.
- **Биелэлтийн хувь** = дууссан / төлөвлөсөн × 100. Камер болон идэвхийн хугацаа нь ажлын чанарыг баталгаажуулахгүй.
